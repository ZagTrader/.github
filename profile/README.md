# ZagTrader

ZagTrader is a capital markets software company headquartered in Dubai. Its front-to-back platform gives brokers, banks, exchanges, custodians, asset managers and family offices one system for trading, risk, margin and securities finance, settlement, custody, accounting and client reporting.

## Free tools

Free browser tools from the teams that build ZagTrader's FIX connectivity and Swift messaging. No sign-up. Messages and logs are parsed in your browser and are not uploaded.

| Tool | What it does | Repository |
|---|---|---|
| [FIX Parser and Log Analyzer](https://fixparser.zagtrader.com/) | Decodes FIX 4.0 to 5.0 SP2 messages and logs tag by tag, checks BodyLength and CheckSum, and turns a log into fill and reject rates, latency percentiles, reject reasons and session health. Includes a message builder, a FIX dictionary by version and a free log analysis API. | [fix-parser](https://github.com/ZagTrader/fix-parser) |
| [MT/MX Parser](https://mt-mx-parser.zagtrader.com/) | Decodes Swift MT (ISO 15022 style) and ISO 20022 (MX) messages: header blocks, every field with its name and value, 16R/16S sequences, ISO 20022 element trees and format checks. | [mt-mx-parser](https://github.com/ZagTrader/mt-mx-parser) |
| [Security Lookup](https://www.zagtrader.com/tools/security-lookup) | Finds a security by ISIN, CUSIP, SEDOL, FIGI, ticker or name. Also [FIGI lookup](https://www.zagtrader.com/tools/figi-lookup), [ISIN lookup](https://www.zagtrader.com/tools/isin-lookup), [CUSIP lookup](https://www.zagtrader.com/tools/cusip-lookup) and [ticker lookup](https://www.zagtrader.com/tools/ticker-lookup). | |
| [Identifier checkers](https://mt-mx-parser.zagtrader.com/tools) | IBAN, BIC, UETR, ISIN, CUSIP, SEDOL, FIGI and CFI checkers and an LEI search. | |
